# TaskFlow - CS4717 Web Technologies I

## Phase 2 - React + TypeScript

Converted TaskFlow from Phase 1 HTML/CSS/JS into a React + TypeScript application.

### Features
- Task List Page with 5 initial tasks
- Create Task Page with form validation
- Delete and Edit tasks
- React Router navigation
- useState for state management
- TypeScript types and props
- Responsive CSS design
- Colored status and priority badges

### How to Run
cd phase2

pnpm install

pnpm run dev
