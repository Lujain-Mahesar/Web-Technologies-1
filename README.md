# TaskFlow - CS4717 Web Technologies I

## Phase 1 - HTML, CSS, JavaScript
Built the TaskFlow UI using vanilla HTML, CSS, and JavaScript.
- Task list with add and delete functionality
- Form validation
- Responsive layout

## Phase 2 - React + TypeScript
Converted TaskFlow from Phase 1 into a React + TypeScript application.
- Two pages: Task List and Create Task
- React Router navigation
- useState for state management
- TypeScript types and props
- Add, Delete, and Edit tasks
- Form validation
- Responsive CSS design
- Colored status and priority badges
- Bonus: Edit and Update task functionality

## How to Run Phase 2
cd phase2

pnpm install

pnpm run dev
